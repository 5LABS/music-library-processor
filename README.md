# Process Music Library
Bun-Script zur Normalisierung einer großen MP3-Bibliothek mit mehr wie ~15000 Files. Verarbeitet ID3-Tags udn ergänzzt fehlende Covers/Tags mit der Deezer Api.

## Aufgabe
* Fehlende Cover & Tags ergänzen
* Tags normalisieren

## Target
Einheitliche Library zur nutzung in Navidrome
